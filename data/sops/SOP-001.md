# SOP-001: Availability Alert Remediation (Host Down / Process Crash)

- **Event Type:** Availability
- **Severity Level:** SEV-1 (Critical)
- **Impacted Entities:** Linux/Windows Hosts, Core Microservices

## Diagnostic Steps

1. Open the Dynatrace Problem Feed and isolate the active Problem ID. Verify the Root Cause block.
2. Navigate to the Host Infrastructure Overview to verify hypervisor/hardware status.
3. Check for concurrent Resource Alerts (e.g., CPU, Memory Exhaustion, Disk Full).
4. View specific process lifecycle logs to see if an OOM Kill (Exit Code 137) or sudden crash occurred.

## Remediation Steps

- **If Process OOM:** Execute an automated service restart via Kubernetes/Ansible. Adjust memory requests/limits if structural.
- **If Host Unreachable:** Trigger an instance reboot via cloud console (AWS EC2 / Azure VM) or escalate to infrastructure team.
- **Verification:** Confirm entity status switches back to green and the Davis Problem automatically closes.
