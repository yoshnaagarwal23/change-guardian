# SOP-002: Service Performance Degradation & Slowdown Triage

- **Event Type:** Slowdown
- **Severity Level:** SEV-2 to SEV-3 (Major/Minor)
- **Impacted Entities:** Web APIs, Microservices, Databases

## Diagnostic Steps

1. Access the Response Time Degradation chart within the active Dynatrace Problem card.
2. Launch the Service Flow interface to trace request paths and locate downstream bottlenecks.
3. Drill down into Method-Level Hotspots to isolate long execution lines, database locks, or code loops.
4. Review SQL statements to check for high execution times or connection pool starvation issues.

## Remediation Steps

- **Downstream Bottleneck:** Contact the respective service or DBA team; apply circuit breakers or caching if available.
- **Sudden Load Spike:** Horizontally scale application replicas/pods to manage the transaction surge.
- **Code Release Regressions:** If the slowdown aligns with a recent deployment marker, initiate an immediate rollback.
