# SOP-004: Resource Contention & Capacity Saturation (CPU / Memory / Disk)

- **Event Type:** Resource
- **Severity Level:** SEV-2 to SEV-3 (Major/Minor)
- **Impacted Entities:** Hosts, Container Nodes, Database Servers

## Diagnostic Steps

1. Access the Dynatrace Problem Card and open the Host Infrastructure / Container Overview panel to identify the specific metric exceeding thresholds (e.g., CPU % Usage, Memory Consumption, Disk Space %).
2. Analyze the Process Performance breakdown to pinpoint the specific application process, memory leak, or runaway thread causing resource exhaustion.
3. Check the Disk IOPS / Storage Analysis tab for high I/O wait times or log file bloat in mounted volumes.
4. Review historical baseline graphs over the last 7 to 30 days to determine if the spike is a predictable load cycle or an anomaly.

## Remediation Steps

- **Disk Cleanup / Volume Expansion:** Truncate or archive non-essential logs, clear temporary files, or request an online cloud volume expansion.
- **Resource Reallocation:** Increase CPU/Memory allocations (vertical scaling) or scale deployment replicas (horizontal scaling) via Kubernetes/Terraform.
- **Process Isolation:** Kill or restart unresponsive/runaway worker processes consuming disproportionate resources.
