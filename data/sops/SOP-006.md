# SOP-006: Custom Event & Metric Alert Triggering

- **Event Type:** Custom Alert
- **Severity Level:** SEV-3 to SEV-4 (Minor/Informational)
- **Impacted Entities:** Custom Business Events, Log Analytics Alerts, Third-Party Telemetry

## Diagnostic Steps

1. Open the Dynatrace Metric Explorer / Custom Charting page to verify the exact metric key and condition that breached the configured threshold.
2. Cross-reference the alert timestamp with Dynatrace Log Management using key extraction fields to trace custom application events.
3. Review the Anomaly Detection Rule Settings for the custom metric to confirm whether the alert was triggered by a static threshold or an adaptive baseline deviation.
4. Verify whether upstream changes or deployments introduced unexpected metric values or log formats.

## Remediation Steps

- **Threshold Tuning / Threshold Maintenance:** Adjust sensitivity, sliding evaluation windows, or threshold boundaries if the alert is determined to be a false positive.
- **Application Configuration Adjustment:** Update feature flags, queue sizes, or rate limits tied to the custom business/application metric.
- **Escalation to Domain Owners:** Forward the alert context and custom metric payload to the specific product or engineering owner assigned to that functional domain.
